🎭 Spectacle+ — Plateforme Mobile de Réservation de Spectacles
Spectacle+ est une application mobile intuitive dédiée à la réservation de spectacles vivants : pièces de théâtre, concerts, spectacles de danse, et autres événements artistiques.

🎯 Objectif
Offrir une solution innovante qui simplifie l’accès du public aux événements culturels tout en optimisant la gestion opérationnelle pour les organisateurs.

🧩 Fonctionnalités principales
Interface moderne et conviviale pour les spectateurs

Consultation de l’offre culturelle disponible

Réservation et gestion des billets de manière simple, rapide et sécurisée

Espace organisateur pour :

Promouvoir les événements

Suivre les ventes en temps réel

Gérer efficacement les ressources

🛠️ Architecture technique
Le projet repose sur une base de données relationnelle robuste (MySQL Workbench) garantissant :

Intégrité et cohérence des données

Sécurité des informations liées aux spectacles, artistes, lieux et utilisateurs

🌐 Vision
Spectacle+ s’inscrit dans la dynamique de digitalisation du secteur culturel. Il illustre comment la technologie, centrée sur l’expérience utilisateur, peut transformer positivement l’accès à la culture et répondre aux nouvelles attentes du public.
